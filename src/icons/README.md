# Iconos SVG locales

`astro-icon` busca aquí los iconos propios del proyecto y avisa en cada build
si la carpeta no existe. Hoy todos los iconos del sitio vienen de los sets de
Iconify instalados (`mdi:`, `ic:`, `oui:`, `simple-icons:`, `svg-spinners:`),
así que esta carpeta está vacía a propósito.

Para añadir uno propio, deja aquí `nombre.svg` y úsalo como `<Icon name="nombre" />`.
